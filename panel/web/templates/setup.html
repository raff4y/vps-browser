Let's set up your private browser

In about two minutes you'll have a real Chromium browser running on this server. You can open it from any phone or computer at your own address, over HTTPS, behind your own sign-in. Every site you visit sees this server's IP address, not yours.

Choose your address

Your browser will live at a domain or subdomain you control, for example browse.example.com. HTTPS is set up for it automatically.

At your domain's DNS provider, add this record:
TypeName / HostValue / Points to
A browse …

Changes usually show up within a few minutes, but can take up to an hour.

Don't have a domain? Get a free one
  1. Go to duckdns.org and sign in (Google, GitHub, etc.).
  2. Type a name (e.g. mybrowser) and click add domain.
  3. In the current ip box, enter … and click update ip.
  4. Enter mybrowser.duckdns.org above.
Using Cloudflare?
Set the record's proxy status to DNS only (grey cloud). The orange-cloud proxy can't carry the live browser stream and blocks the HTTPS certificate.
